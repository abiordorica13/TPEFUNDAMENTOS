# Trabajo Práctico Especial – Fundamentos de la Ciencia de Datos

## Descripción

Este proyecto realiza un análisis exploratorio y estadístico del conjunto de datos **EPA Fuel Economy – Model Year 2025**, correspondiente a vehículos del año modelo 2025.

Se realizan tareas de exploración, limpieza de datos, análisis de distribuciones y validación de hipótesis univariadas, bivariadas y multivariadas.

## Contenido del repositorio

- `TPE_Grupo19_Fundamentos.ipynb`: notebook con el desarrollo completo del trabajo.
- `25-testcar-2026-01-21.xlsx`: conjunto de datos original utilizado.
- `INFORME.pdf`: informe con los principales resultados y conclusiones.
- `requirements.txt`: dependencias necesarias para ejecutar el proyecto.

## Requisitos

- Python 3.
- Jupyter Notebook.
- Las librerías indicadas en `requirements.txt`.

## Instalación

1. Clonar el repositorio:

   git clone https://github.com/abiordorica13/TPEFUNDAMENTOS.git


2. Ingresar a la carpeta del proyecto:

   cd TPEFUNDAMENTOS


3. Instalar las dependencias:

   pip install -r requirements.txt

## Ejecución

1. Abrir Jupyter Notebook:

   jupyter notebook


2. Abrir el archivo `TPE_Grupo19_Fundamentos.ipynb`.

3. Ejecutar las celdas de la notebook en orden, desde el comienzo hasta el final.

**Importante:** el archivo Excel debe encontrarse en la misma carpeta que la notebook para que pueda ser leído correctamente.
